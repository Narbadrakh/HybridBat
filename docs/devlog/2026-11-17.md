# 2026-11-17: Database (2-р алхам) — Supabase + Drizzle

Зарууд mock файлаас биш Supabase Postgres-оос ирдэг боллоо.

## Хийсэн ажил

### 1. `listings` хүснэгт (`lib/db/schema.ts`)
- Талбарууд: `title`, `description`, `type` (battery / repair / cell), `model_slug`, `price` (₮), `location`, `warranty_months`, `phone`, `status` (active / sold / hidden), `user_id` (Clerk-д), `created_at`, `updated_at`
- **RLS асаалттай, policy-гүй:** Supabase-ийн REST API (publishable/anon түлхүүр)-аар уншиж бичих боломжгүй. Шалгасан: `/rest/v1/listings` → `[]`
- Партиал index: зөвхөн `status = 'active'` мөрүүд (огноогоор, загвар + огноогоор)
- CHECK: үнэ, баталгааны сар сөрөг байж болохгүй

### 2. Апп ↔ DB
- `lib/db/index.ts` — холболт (postgres-js + Drizzle)
- `lib/listings.ts` — `getLatestListings()`, `getListingsByModel()` (`server-only`; утас, user_id жагсаалтад гарахгүй)
- `lib/listing-types.ts` — төрөл, шошго, `formatPrice`
- Нүүр хуудас, `/models/[slug]` — `revalidate = 60` (ISR, 1 минут тутам шинэчилнэ)
- `lib/mock-data.ts` устсан; 6 жишээ зар `scripts/seed.ts` руу шилжсэн

### 3. Командууд
| Команд | Үүрэг |
|---|---|
| `npm run db:generate` | schema өөрчлөгдсөний дараа шинэ migration үүсгэх |
| `npm run db:migrate` | migration-уудыг Supabase дээр ажиллуулах |
| `npm run db:seed` | хоосон DB-д жишээ зар нэмэх (production-д ажиллахгүй) |
| `npm run db:studio` | Drizzle Studio (DB-г браузераар харах) |

### 4. Supabase agent skills
`npx skills add supabase/agent-skills` → `.claude/skills/` (supabase, supabase-postgres-best-practices)

### 5. Шалгасан зүйлс

- RLS асаалттай, index-үүд үүссэн, сөрөг үнэ CHECK-ээр татгалзсан
- `/`, `/models/prius-30` DB-ийн зарыг харуулж байна (200)
- `tsc`, `eslint`, `next build` алдаагүй
- Засвар: dev server хуучин (буруу нууц үгтэй) холболтоо `globalThis` дээр хадгалж 500 өгч байсан → холболтыг URL-аар түлхүүрлэж, `.env.local` өөрчлөгдвөл шинээр үүсгэдэг болгосон

## Тохиргоо (`.env.local`, git-д орохгүй — `.env.example`-г үз)

- `DATABASE_URL` — Transaction pooler, порт **6543** (апп)
- `DIRECT_URL` — Session pooler, порт **5432** (migration)
- Хост: `aws-1-ap-southeast-1.pooler.supabase.com` (Сингапур)

## Анхаарах зүйлс

- **`db.<ref>.supabase.co` (Direct connection) ажиллахгүй** — зөвхөн IPv6, энэ сүлжээнд хүрэхгүй. Үргэлж pooler хост ашиглана.
- Connection string-д нууц үгийг `[ ]` хаалтгүй бичнэ.
- **`npm run build` DB-тэй холбогдоно** (хуудсуудыг build үед бэлддэг). Vercel дээр `DATABASE_URL`-ийг Environment Variables-д нэмэх.
- Supabase-ийн `sb_secret_…` түлхүүр болон DB нууц үг чатад орсон — солих.
- Жишээ 6 зар зохиомол хэвээр.
