# 2026-11-16: Front-end UI (1-р алхам)

Архитектурын диаграмын дагуу эхний давхарга болох **User's browser → Your app (pages)**-г хийсэн.
Өгөгдөл одоохондоо жишээ (mock). Backend холбоогүй.

## Хийсэн ажил

### 1. Нүүр хуудас (`/`)
- **Header:** дээрээ наалттай, лого, цэс, "+ Зар нэмэх" товч, утасны цэс (JavaScript-гүй)
- **Hero:** "CHECK HYBRID SYSTEM" анхааруулгатай самбарын зураг (`public/hero-warning.jpg`), зүүн талд текст, товчнууд, загварын хурдан холбоосууд
- **Загвараар хайх:** 7 загварын карт → `/models/[slug]` руу холбоно
- **Шинэ зарууд:** 6 жишээ зарын карт
- **Яаж ажилладаг вэ?** 3 алхам + зарлагчдад зориулсан уриалга
- **Footer:** загвар, холбоосууд

### 2. Загварын хуудас (`/models/[slug]`)
Жишээ нь `/models/prius-20`. Бүх 7 загварын хуудас build хийх үед бэлэн болдог.
- Үйлдвэрлэсэн оноор нь сонгох товчнууд (Prius 20 / 30 / 50)
- Үе бүрийн батерейны үзүүлэлт: төрөл, хүчдэл, модулийн тоо, багтаамж, байршил
- Prius 50: NiMH, Li-ion хоёр хувилбар; Camry: AHV40, AVV50 хоёр үе
- Үеүдийн харьцуулалт хүснэгт
- Батерей муудаж буйн шинж тэмдэг
- **Засварын сонголтууд** (хямдаас үнэтэй рүү, ₮–₮₮₮₮):
  - Урьдчилан сэргийлэх: оношилгоо, хөргөлтийн сэнс шалгах/цэвэрлэх, 12V аккумулятор, холбогч цэвэрлэх
  - Засвар: тэнцвэржүүлэх, модуль солих, сэргээсэн батерей, шинэ батерей
  - Зардал хэмнэх зөвлөгөө
- Тухайн загварын зарууд

### 3. Дизайн шийдлүүд
- Бүх хэсгийн нэг ижил өргөн: `container-page` (1408px), `app/globals.css` дотор
- Брэндийн өнгө: ногоон `#138a6e`, hover үед `#0f6f58` (бүх улаан товчийг ногоон болгосон)
- Header, Footer `app/layout.tsx`-д байрладаг тул бүх хуудсанд гарна
- Hero зураг: ENNOCAR логотой батерейны зургийг хассан

## Файлын бүтэц

```
app/
  layout.tsx                 Header + Footer, lang="mn"
  page.tsx                   Нүүр хуудас
  globals.css                container-page
  _components/               Header, Hero, ModelCards, FeaturedListings, HowItWorks, Footer
  models/[slug]/page.tsx     Загварын хуудас
lib/
  models.ts                  Загвар, үе, батерейны үзүүлэлт
  mock-data.ts               Жишээ зарууд (түр)
public/
  hero-warning.jpg           Hero зураг
```

## Анхаарах зүйлс

- **Жишээ зарууд:** `lib/mock-data.ts` доторх 6 зар зохиомол (үнэ, байршил бүгд). Бодит биш.
- **Нягтлах өгөгдөл** (`lib/models.ts`):
  - Alphard ATH20: хүчдэл, модулийн тоо, байршил тодорхойгүй ("Тодруулах")
  - Harrier AVU65: утгууд баталгаажаагүй
  - Prius 50: аль комплектацид NiMH / Li-ion болохыг тодруулах
- **Hero зураг** өөр сайтын нийтлэлээс авсан. Нийтэд гаргахаас өмнө өөрийн эсвэл эрхтэй зургаар солих.
- **Байхгүй хуудсууд (404):** `/listings`, `/listings/[id]`, `/listings/new`, `/sign-in`
- **Ашиглагдаагүй файлууд:** `public/hero-battery.webp`, `hero-battery-clean.webp`, `hero-dashboard.webp`. Хэрэггүй бол устгах.
- Next.js 16: `<Image priority>` хуучирсан тул `preload` ашиглана. `params` нь Promise (`await params`).
