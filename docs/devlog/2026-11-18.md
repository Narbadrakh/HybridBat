# 2026-11-18: Нэвтрэлт (3-р алхам) — Clerk + "Зар нэмэх" форм

## Хийсэн ажил

### 1. Архитектурын диаграм
- `docs/architecture.png` + `docs/architecture.md` — 8 сервисийн төлөвийн хүснэгт
- Өдөр бүрийн devlog-д диаграмтай тулгасан хэсэг бичих дүрэм

### 2. Clerk нэвтрэлт (`@clerk/nextjs` 7, Core 3)
- `app/layout.tsx` — `<ClerkProvider>` (body дотор), **монгол хэл** (`@clerk/localizations` → `mnMN`)
- `/sign-in`, `/sign-up` — Clerk-ийн бэлэн маягт, манай сайтын дотор
- `app/_components/AuthNav.tsx` — Header: нэвтрээгүй бол "Нэвтрэх", нэвтэрсэн бол `<UserButton />`.
  Browser дээр (`useAuth`) шалгадаг тул нүүр, загварын хуудсууд **статик (ISR) хэвээр**
- `proxy.ts` — `clerkMiddleware()` л. `createRouteMatcher` deprecated болсон тул хамгаалалтыг хуудас/action дотор хийнэ

### 3. "Зар нэмэх" (`/listings/new`)
- `page.tsx` — `auth.protect()`: нэвтрээгүй бол `/sign-in` руу
- `ListingForm.tsx` — гарчиг, төрөл, загвар, үнэ, баталгаа, байршил, утас, тайлбар; алдааг талбар бүрийн доор (`useActionState`)
- `actions.ts` (Server Action) — `auth()`-аар дахин шалгана, бүх талбарыг сервер дээр баталгаажуулна, `user_id`-тэй хадгална,
  `revalidatePath` → тухайн загварын хуудас руу шилжинэ

### 4. Шалгасан зүйлс
- `tsc`, `eslint`, `next build` алдаагүй; `/`, `/models/*` статик (1 мин ISR), `/listings/new`, `/sign-in`, `/sign-up` dynamic
- Clerk secret key-г Clerk API-аар шалгасан (200)
- Бүртгүүлэх маягт монголоор гарч байгааг хэрэглэгч browser дээр харсан

## Тохиргоо (`.env.local`)
```
NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY=pk_test_...
CLERK_SECRET_KEY=sk_test_...
NEXT_PUBLIC_CLERK_SIGN_IN_URL="/sign-in"
NEXT_PUBLIC_CLERK_SIGN_UP_URL="/sign-up"
```
`NEXT_PUBLIC_*` өөрчилсний дараа dev server-ээ дахин асаана.

## Тулгарсан асуудлууд
- **Clerk dashboard бүртгэл** "Verifying your request" дээр гацсан → өөр browser / Google-ээр
- **Secret key invalid** — `.env.local`-ийн сүүлийн мөр newline-гүй байсан тул нэмсэн мөр түлхүүрт наалдсан. Салгаж зассан.
- **Монголын утасны дугаар Clerk-д дэмжигдэхгүй** (SMS) → Clerk dashboard → User & authentication → **Phone number-ийг унтраах**.
  Утсыг зар нэмэх форм дээр авдаг тул Clerk-д хэрэггүй.
